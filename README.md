## 👨‍💻 About Me

> I engineer scalable web applications and intelligent data systems that turn raw data into actionable decisions.

- 🎓 **Undergraduate Informatics Student** at Gunadarma University, focusing on Applied AI and Software Engineering.
- 🔬 **Thesis Research**: Developing **SentiRank**, an end-to-end decision-support system utilizing **IndoBERT** sentiment inference, **SVM** aspect classification, and **AHP/Fuzzy AHP** multi-criteria ranking.
- 💻 **Fullstack & Microservices**: Building performant web apps using **Next.js**, **TypeScript**, **FastAPI**, and containerized environments with **Docker**.
- 🛠️ **Engineering Philosophy**: Clean architecture, measurable impact, and maintainable code over unnecessary complexity.
